# Architecture — dcc-bigfred/proto

Go and Rust libraries for LocoNet, Z21 LAN, and WiThrottle. Both languages
speak the same wire semantics. This document describes the **libraries**, not
Digitrax PE / JMRI (those live in [`docs/`](docs/)).

BigFred and LongFred are **not** changed in this repository's first phases.
Cutover is a later initiative.

## Layout

```text
proto/
  ARCHITECTURE.md
  plans/                # design plans
  docs/                 # loconet.md, z21.md, withrottle.md — protocol specs
  testdata/             # {loconet,z21,withrottle}/*.json — generated by Go
  go/
    go.mod              # module github.com/dcc-bigfred/proto/go
    pkgs/
      commandstation/   # Station clients (Z21, LocoNet, WiThrottle)
      z21/              # Z21 protocol + UDP server
      withrottle/       # WiThrottle protocol + TCP server + client
      loconet/          # LocoNet gateway + shared framing
      drive/            # DriveHost used by Z21/WiThrottle servers
      telemetry/        # OTel Register* (only package that imports otel)
    internal/vectors/   # golden JSON schema (not a public API)
    cmd/gen-vectors/    # writes testdata/
    cmd/loopback-host/  # Go Listen for Rust interop tests
  rust/
    z21/  withrottle/   # CLIENT: no_std, no alloc, no sockets (LongFred)
    z21-server/  withrottle-server/  loconet/  commandstation/  # std dummies
    interop/            # Rust client ↔ Go server loopback (Linux CI)
```

Go lives under `go/` so the module path is `github.com/dcc-bigfred/proto/go`.

## Layers

```text
  handset / JMRI / LongFred
           │
           ▼
  server listen (Z21 UDP, WiThrottle TCP, LocoNet gateway)
           │  DriveHost / NotifyLocoState
           ▼
  consumer (BigFred Router — later; tests use a recorder)
           │
           ▼
  Station client  ──►  physical command station
           │
           ▼
  codec (frames, checksums, line grammar)
```

- **Codec:** encode/decode only. No sockets.
- **Client (`Station`):** dials a real command station (serial, TCP, UDP).
- **Server:** listens; maps protocol verbs onto `DriveHost`; pushes state with
  `NotifyLocoState` / `NotifyTrackPower`.
- **LocoNet gateway:** one upstream transport, N downstream listeners; every
  frame is forwarded to the other ends. Not a Digitrax slot master.

Pairing, roster policy, Redis, and OTLP export stay in the consumer.

## Go client (`Station`)

Same surface as bigfred `pkgs/loco/commandstation`:

`SetSpeed`, `GetSpeed`, `SendFn`, `ListFunctions`, `ReadCV`, `WriteCV`,
`CleanUp`, plus optional `SlotManager`, `TrackPowerController`, `MetricsSource`.
Recommended constructor: `Open(uri)` — scheme selects the driver
(`z21://`, `withrottle://`, `serial://`, `loconet-tcp://`, `lbserver://`;
aliases `udp://` and `tcp://` are also accepted).
Typed constructors (`NewZ21Roco`, `NewLocoNetSerial`, `NewLocoNetTCP`,
`NewLocoNetTCPBinary`, `NewWiThrottle`) remain for when the transport is known.

`NewWiThrottle(host, port, opts …)` implements `Station` (JMRI / DCC-EX /
LNWI / RB1110). CV ops return `ErrUnsupported`. Device id defaults to
`proto-<8 hex>`. Scan the LAN with `WiThrottleAutodetection` (TCP 12090,
URI `withrottle://host:port`), then `Open(c.URI)`.

## Go server (`DriveHost`)

Shared by Z21 and WiThrottle. BigFred will later wrap this around
`InboundDrivePort`.

```go
type ClientID string // UDP addr, or TCP conn + HU

type LocoState struct {
    Addr      uint16
    Speed     uint8
    Forward   bool
    Steps     uint8
    Functions uint32 // F0..F31
}

type DriveHost interface {
    SetSpeed(client ClientID, addr uint16, speed uint8, forward bool, steps uint8) error
    SetFunction(client ClientID, addr uint16, fn uint8, on bool) error
    LocoState(addr uint16) (LocoState, error)
    SetTrackPower(client ClientID, on bool) error
    Release(client ClientID, addr uint16)
}

// Server → handsets (loco changed from another source):
func (s *Server) NotifyLocoState(st LocoState)
func (s *Server) NotifyTrackPower(on bool)
```

- `z21.Listen(bind, host)` — default `:21105`
- `withrottle.Listen(bind, host)` — default `:12090`

CV3/CV4 and function-key pairing stay in BigFred as a `DriveHost` wrapper.

## LocoNet gateway

```go
up, _ := commandstation.OpenLocoNetSerial("/dev/ttyUSB0", 57600)
gw := loconet.NewGateway(up)
gw.Listen(":1234", loconet.Binary)
gw.Listen(":5550", loconet.ASCII)
```

A virtual LocoNet command station (opcode → `DriveHost`, slot table) is a
**later plan**.

## Rust

**Clients `z21` and `withrottle` (hard requirement for LongFred):** `#![no_std]`,
no `alloc`, no sockets. Shape matches LongFred adapters: `on_connect(out)`,
`on_bytes(in, emit)`, `encode(cmd, out)` into `heapless` buffers. TCP/UDP stay
in firmware (`embassy-net`).

**No consumer yet → dummy `std` crates:** `z21-server`, `withrottle-server`,
`loconet`, `commandstation`. Public API mirrors Go; implementation is the
minimum needed to compile and (later) interop. Marked experimental.

## Telemetry

Hot path: lock-free atomics, no OTel per frame. Snapshots stay on the driver.

Package `go/pkgs/telemetry` is the **only** importer of `go.opentelemetry.io/otel`
and `otel/metric` (API, not SDK):

`RegisterLocoNet(meter, src, attrs)`, `RegisterZ21`, `RegisterWithrottle`.

Without a `MeterProvider` this is a no-op meter. Instrument names:
`proto.loconet.*`, `proto.z21.*`, `proto.withrottle.*`. Instance attributes
(`layout.id`, `command_station.id`) come from the consumer. Rust clients: counters
only, no OTel.

## Go ↔ Rust equivalence

Libraries do not link to each other in production. No FFI / CGO on the
firmware path.

**Layer 1 — vectors generated by Go.** `go run ./cmd/gen-vectors` writes
`testdata/{proto}/*.json`. Binary protocols store the wire as `hex`; text
protocols (WiThrottle) store it as `line`. Go and Rust tests both read those
files. CI job `vectors-fresh` fails if generation would change the tree
(`git diff --exit-code`).

**Layer 2 — network interop (Linux).** Rust no_std codec + `std::net` in tests
against Go `Listen*`, plus same-language loopbacks (Go client ↔ Go server).

Not compared: pairing, BigFred roster, OTLP, LocoNet TX pacer timing, ESP.
